# Map assets and attribution

The `public/maps/` directory contains original PepeMaps map tiles, markers, and overviews. `public/pepe-brand-icon.svg` is a brand asset. The viewer also depicts Minecraft worlds and builds by other people.

These assets are present so the private review build looks like the existing site. Their inclusion here does **not** mean that the Apache-2.0 license in `LICENSE` covers them. Access to an image on a public website is not a license to redistribute or modify it.

Before publishing this repository, determine the rights and intended terms for the map tiles, logo, names, and player-created builds. Add explicit asset permissions and credits, or remove assets that cannot be distributed. The software license and `NOTICE` cover the application source code only.
